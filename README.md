# We Them Media: the public record

This is the public copy of [wethem.xyz](https://wethem.xyz), a community-driven media platform: the pages, and the transcripts of
the videos published there.

It is a snapshot. The site is built and deployed from a private repository. This repository is kept in step with it, and changes
you propose here are reviewed and, if accepted, carried back.

## What is here

- The pages the site serves (HTML, CSS, JavaScript, images).
- `transcripts/<video id>.txt` and `.en.vtt`: the text of each published video, with corrections applied.
- `transcripts/speakers/<video id>.json`: which speaker says each paragraph.

## What is not

Unpublished and held material, partner and client work, the build and its tools, and anything private. If a file is not here
it is not because it was forgotten.

## How to help

- **A wrong word or a wrong name in a transcript:** open an issue (use "Fix a fact or a transcript") or send a pull request that
  changes the `.txt` file. Names and terms are corrected; speech is not. We check a correction against the tape.
- **Something wrong on a page:** open an issue.
- **A security problem:** see `SECURITY.md`. Do not open a public issue.

Read `CONTRIBUTING.md` first. Sign off your commits (`git commit -s`).
