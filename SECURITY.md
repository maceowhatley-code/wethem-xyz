# Security policy

Found a security problem with the site or this repository? Please do not open a public issue.

Email **wethem.xyz@gmail.com** with "Security" in the subject, or use GitHub's private vulnerability reporting on this
repository. Tell us what you found and how to see it. We will answer within a few days and fix it before we say anything public.

This repository holds no credentials and deploys nothing. If you find a secret in it, tell us at once and we will rotate it.
